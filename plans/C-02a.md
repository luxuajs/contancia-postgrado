## Objetivo
El backend compara cada petición y cada respuesta JSON con `contracts/openapi.yml` y escribe
una línea `[contrato] {...}` por cada discrepancia distinta, **sin bloquear ni cambiar nada**.
Se apaga con `CONTRATO_VALIDACION=off`. Existe el contrato empaquetado
`contracts/dist/openapi.bundled.yml`, que es el que lee el validador.

## Contrato aplicable
No cambia el contrato. El validador lo carga entero desde el bundle. Lo que hay que saber de él:
- OpenAPI **3.1.0**, 14 operaciones bajo `/api/*`; `operationId` en todas.
- `openapi.yml` referencia `./common/errores.yml#/respuestas/...` (archivo externo). El
  validador **falla** con `$ref` externos en respuestas (`Cannot read properties of undefined
  (reading 'content')`, comprobado al planificar). Por eso se le da el bundle, donde todos los
  `$ref` son internos.
- Seguridad: esquema `sesion` (Bearer JWT). Las rutas públicas tienen `security: []`.
- Rutas con parámetros: `/api/constancias/{cedula}`, `/api/constancias/download/{cedula}`,
  `/api/constancias/pdf/{cedula}`, `/api/usuarios/{id}` (`id` entero ≥ 1).
- Cuerpo de error: `{ error: string, detalles?: [{campo, mensaje}], codigo?, detalle? }`.

## Decisiones ya tomadas
- **`express-openapi-validator@5.6.2`** (versión exacta) — hace el enrutado del contrato,
  OAS 3.1 y validación de respuestas con `onError`. Probado al planificar con este contrato,
  Express 4 y TypeScript `strict`: funciona. No se escribe un validador propio con Ajv.
- **Modo aviso = no bloquear nunca.** Los validadores se ejecutan en cadena dentro de un único
  middleware; si uno da error, se registra y se pasa al siguiente. La respuesta sale tal cual
  (`onError` solo registra).
- **`validateSecurity: false`** — la autenticación la hace `requireAuth`; aquí solo la forma.
- **Falla abierto**: si falta el archivo del contrato, un aviso al arrancar y sin validación.
  En modo aviso el contrato nunca tumba la API.
- **Deduplicación en memoria** (una línea por discrepancia distinta, tope 1000) — basta para
  convertir derivas en tareas (C-02b).
- **El bundle se versiona** en `contracts/dist/` (convención del método). En Docker se monta
  como volumen de solo lectura; el `Dockerfile` no cambia (su contexto es `./backend`).
- El validador **convierte tipos** de `req.params`/`req.query` a nivel de app (p. ej. `id` →
  número). Sin efecto: las rutas viven en sub-routers que recalculan `req.params` como texto
  (comprobado) y ninguna ruta lee `req.query`.

```ts
import fs from 'fs';
import path from 'path';
import { NextFunction, Request, RequestHandler, Response } from 'express';
import * as OpenApiValidator from 'express-openapi-validator';

// Modo aviso: compara peticiones y respuestas con el contrato y registra la deriva,
// sin bloquear ni cambiar la respuesta. Cada línea "[contrato]" es una posible tarea.

type Deriva = {
  dir: 'peticion' | 'respuesta';
  metodo: string;
  ruta: string;
  status?: number;
  errores: { campo: string; mensaje: string }[];
};

// atajo: deduplicación en memoria con tope fijo; si hiciera falta histórico, a un log externo.
const vistas = new Set<string>();
const MAX_VISTAS = 1000;

/** Escribe una deriva una sola vez por proceso (nunca el cuerpo: puede llevar datos personales). */
function avisar(d: Deriva): void {
  const clave = JSON.stringify([d.dir, d.metodo, d.ruta, d.errores]);
  if (vistas.has(clave)) return;
  if (vistas.size < MAX_VISTAS) vistas.add(clave);
  console.warn('[contrato]', JSON.stringify(d));
}

/** Ruta del contrato (p. ej. /api/constancias/{cedula}); nunca la URL real, que lleva la cédula. */
function rutaDe(req: Request): string {
  const openapi = (req as Request & { openapi?: { openApiRoute?: string } }).openapi;
  return openapi?.openApiRoute ?? `${req.baseUrl}${req.path}`.slice(0, 120);
}

function aErrores(err: unknown): Deriva['errores'] {
  const e = err as { errors?: { path?: string; message?: string }[]; message?: string };
  if (Array.isArray(e.errors) && e.errors.length > 0) {
    return e.errors.map((x) => ({ campo: x.path ?? '', mensaje: x.message ?? '' }));
  }
  return [{ campo: '', mensaje: e.message ?? String(err) }];
}

/**
 * Middleware de validación en modo aviso, o null si está apagado o falta el contrato.
 * Va después de express.json() y antes de las rutas.
 */
export function crearValidadorContrato(modo: 'off' | 'aviso', ruta: string): RequestHandler | null {
  if (modo === 'off') return null;

  const apiSpec = path.resolve(ruta);
  if (!fs.existsSync(apiSpec)) {
    // Falla abierto a propósito: en modo aviso el contrato nunca tumba la API.
    console.warn(`[contrato] No se encontró ${apiSpec}; validación desactivada.`);
    return null;
  }

  const validadores = OpenApiValidator.middleware({
    apiSpec,
    validateRequests: true,
    validateResponses: {
      // Se llama en res.json() con una respuesta fuera de contrato; la respuesta sale igual.
      onError: (err, _json, req) =>
        avisar({ dir: 'respuesta', metodo: req.method, ruta: rutaDe(req), errores: aErrores(err) }),
    },
    // La autenticación la hace requireAuth; aquí solo se compara la forma.
    validateSecurity: false,
  });

  return (req: Request, res: Response, next: NextFunction): void => {
    let i = 0;
    // Ejecuta los validadores en cadena; un error se registra y se sigue con el siguiente.
    const siguiente = (err?: unknown): void => {
      if (err) {
        const status = (err as { status?: number }).status;
        avisar({ dir: 'peticion', metodo: req.method, ruta: rutaDe(req), status, errores: aErrores(err) });
      }
      const mw = validadores[i++];
      if (!mw) {
        next();
        return;
      }
      try {
        mw(req, res, siguiente);
      } catch (e) {
        siguiente(e);
      }
    };
    siguiente();
  };
}
```

4. Crear `backend/scripts/probarContrato.ts` con exactamente (es la comprobación; no usa base
   de datos ni el `env` de la app):

```ts
// Comprobación del validador en modo aviso, sin base de datos:
// npx tsx scripts/probarContrato.ts   (desde backend/, con el contrato empaquetado)
import assert from 'assert';
import express from 'express';
import { crearValidadorContrato } from '../src/middleware/contrato';

const avisos: string[] = [];
const warnOriginal = console.warn;
console.warn = (...args: unknown[]) => avisos.push(args.join(' '));

const validador = crearValidadorContrato('aviso', '../contracts/dist/openapi.bundled.yml');
assert.ok(validador, 'no se cargó el contrato empaquetado');

const app = express();
app.use(express.json());
app.use(validador);
// Respuestas a propósito: una conforme y dos fuera de contrato.
app.get('/api/health', (_req, res) => {
  res.json({ status: 'ok', servicio: 'facesuc-constancias', fecha: new Date().toISOString() });
});
app.get('/api/constancias/:cedula', (_req, res) => {
  res.status(404).json({ mensaje: 'sin campo error' });
});
app.post('/api/auth/login', (_req, res) => {
  res.status(400).json({ error: 'Datos inválidos' });
});

const servidor = app.listen(0, async () => {
  try {
    const { port } = servidor.address() as { port: number };
    const pedir = async (metodo: string, ruta: string, cuerpo?: object) => {
      const r = await fetch(`http://127.0.0.1:${port}${ruta}`, {
        method: metodo,
        headers: { 'content-type': 'application/json' },
        body: cuerpo ? JSON.stringify(cuerpo) : undefined,
      });
      return { status: r.status, cuerpo: await r.json() };
    };

    // 1. Respuesta conforme: sin avisos.
    assert.equal((await pedir('GET', '/api/health')).status, 200);
    assert.equal(avisos.length, 0, `avisos inesperados: ${avisos.join('\n')}`);

    // 2. Respuesta fuera de contrato: sale igual, se avisa una vez, sin la cédula real.
    const r = await pedir('GET', '/api/constancias/12345678');
    assert.deepEqual(r, { status: 404, cuerpo: { mensaje: 'sin campo error' } });
    await pedir('GET', '/api/constancias/12345678');
    assert.equal(avisos.length, 1, 'la deriva repetida debe avisarse una sola vez');
    assert.match(avisos[0], /"dir":"respuesta".*\/api\/constancias\/\{cedula\}/);
    assert.ok(!avisos[0].includes('12345678'), 'el aviso no debe llevar la cédula');

    // 3. Petición fuera de contrato: no se bloquea y no se registra la contraseña.
    const l = await pedir('POST', '/api/auth/login', { password: 'secreta' });
    assert.equal(l.status, 400);
    assert.equal(l.cuerpo.error, 'Datos inválidos');
    assert.equal(avisos.length, 2);
    assert.match(avisos[1], /"dir":"peticion".*\/api\/auth\/login/);
    assert.ok(!avisos[1].includes('secreta'), 'el aviso no debe llevar el cuerpo');

    // 4. Sin contrato: devuelve null y no lanza.
    assert.equal(crearValidadorContrato('aviso', '/no/existe.yml'), null);
    assert.equal(crearValidadorContrato('off', '../contracts/dist/openapi.bundled.yml'), null);

    console.warn = warnOriginal;
    console.log('OK: validador de contrato en modo aviso');
  } catch (e) {
    console.warn = warnOriginal;
    console.error(e);
    process.exitCode = 1;
  } finally {
    servidor.close();
  }
});
```

## Seguridad
- **A09 Logging** — los avisos llevan solo dirección, método, **ruta del contrato**
  (`/api/constancias/{cedula}`, no la URL con la cédula real) y mensajes del validador
  (`campo` + `mensaje`, sin valores). **Nunca** `req.body` ni el JSON de respuesta (contraseñas,
  tokens de enlace, notas y cédulas). El paso 4 lo comprueba.
- **A10 Exceptional Conditions** — en modo aviso falla abierto a propósito (la validación no es
  un control de seguridad: la entrada la siguen validando los esquemas Zod de cada ruta y la
  auth `requireAuth`/`requireRole`). Excepciones del validador se capturan y se registran.
- **A03 Supply Chain** — una sola dependencia nueva, versión exacta, fijada en el lockfile.
- **A02 Misconfiguration** — el contrato se monta `:ro` en Docker; no se expone por HTTP.
